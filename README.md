# Meeting Copilot

**EN:** A real-time AI copilot for work meetings. It captures meeting audio (browser tab/screen or system sound via BlackHole), streams it to Deepgram for live ru/en transcription, and shows Claude's suggested answers in a floating window over the meeting app. After the call it produces a summary and action items, and you can ask questions about the recording. Python server core (WebSocket API, audio DSP, knowledge base from your own notes) + web client + Electron desktop app for macOS/Windows. Tests run with pytest.

**Stack:** Python 3.12, uv, FastAPI/WebSockets, Deepgram Nova-3, Anthropic Claude, Electron, Swift (macOS system audio capture), Docker, Caddy.

---


Копилот для рабочих встреч: слушает встречу (вкладка/экран в браузере или системный звук через BlackHole),
транскрибирует (Deepgram), показывает ответы Claude в плавающем окне поверх приложения встречи, после встречи —
конспект. Архитектура: серверное ядро на Python + веб-клиент; терминальный клиент с локальным захватом — для
разработки и десктопного режима. Подробности и план — в `CLAUDE.md` (v2), прежний десктопный бриф — `docs/brief-v1-desktop.md`.

## Установка (один раз)

```bash
cd ~/meeting-copilot
uv sync                      # создаст .venv с Python 3.12 и поставит зависимости
cp .env.example .env         # и впиши ключи (DEEPGRAM_API_KEY, ANTHROPIC_API_KEY)
```

### macOS — системный звук через BlackHole

1. `brew install --cask blackhole-2ch` (спросит пароль администратора).
2. **Audio MIDI Setup** → «+» (внизу слева) → **Create Multi-Output Device**.
3. Отметь наушники/колонки **и** `BlackHole 2ch`; у BlackHole включи *Drift Correction*.
4. Правый клик по Multi-Output Device → **Use This Device For Sound Output**.
5. Разрешения: System Settings → Privacy & Security → **Microphone** → разреши Terminal (или VS Code).
   Для глобальных хоткеев (Шаг 4) там же понадобится **Accessibility**.

Громкость при Multi-Output регулируется не клавишами ⌘/F11–F12, а в самом приложении или
в Audio MIDI Setup — это особенность macOS.

### Windows

Ничего дополнительного: `uv sync --extra win` ставит `pyaudiowpatch`, системный звук берётся
через WASAPI loopback с устройства вывода по умолчанию.

## Проверка Шага 1 — аудио

```bash
uv run python -m copilot.audio.devices
```

Покажет список устройств и два живых индикатора уровня. Включи YouTube и скажи пару слов —
должны шевелиться оба: `them` (системный звук) и `me` (микрофон). `Ctrl+C` — стоп и итог.

```bash
uv run python -m copilot --check     # сводка: ключи, context/, устройства
```

## Шаг 2 — живой транскрипт

Нужен `DEEPGRAM_API_KEY` в `.env`.

```bash
uv run python -m copilot replay tests/fixtures/meeting_ru_en.wav   # тестовая запись ru+en → транскрипт
uv run python -m copilot cli --mic-only                             # говори в микрофон → строки `me:`
uv run python -m copilot cli                                        # BlackHole (them) + микрофон (me)
uv run python -m copilot serve                                      # отдельный сервер для браузера (Шаг 4)
```

`cli` и `replay` сами поднимают сервер внутри процесса и говорят с ним по тому же WebSocket-протоколу,
что будет у браузера. Серым — промежуточный текст, строки `them:`/`me:` — законченные реплики.

## Шаг 3 — ответы Claude

Нужен `ANTHROPIC_API_KEY` в `.env`.

```bash
uv run python -m copilot replay tests/fixtures/meeting_ru_en.wav --ask --summary   # ответ на последний вопрос + итоги
uv run python -m copilot cli --mic-only                                            # живой режим
```

В живом режиме: **Enter** — ответ на последний вопрос собеседника, **текст + Enter** — свой вопрос,
`/s` — итоги встречи, `/c` — отменить ответ, `/r` — перечитать `context/`.
Живые ответы — Haiku без «размышлений» (≈0.9 с до первого слова), итоги — Sonnet.
Чем подробнее заполнены `context/*.md`, тем точнее ответы от первого лица; когда контекст станет
достаточно большим, включится кэш промпта (видно как `cache > 0` в строке после ответа).

## Шаг 4 — сайт

```bash
uv run python -m copilot serve --open      # печатает ссылку с токеном и открывает её
```

Открывай в **Chrome/Edge**. «Поделиться экраном и начать» → выбери **вкладку** со встречей и включи
«Поделиться звуком вкладки» (для десктопного Zoom/Teams на Mac — режим «Устройство (BlackHole)»).
Сверху — твой экран, снизу — ответы Claude, справа — транскрипт и история ответов.
**⌥Space** — ответ на последний вопрос, **⌥⇧A** — Auto, **⌥⇧P** / «Поверх окон» — окно ответов поверх Zoom.

## Приложение для Mac и Windows (`desktop/`)

Обёртка над тем же сайтом плюс то, чего браузер не умеет:
- **Текст поверх всего экрана** — по центру (или сверху/снизу), поверх видео встречи, во всех окнах,
  вкладках, рабочих столах и в полноэкранном режиме. Окно прозрачное для мыши — кликать сквозь него можно.
- **Глобальные клавиши** (работают, даже когда активен Zoom/Meet):
  ⌘⇧Space ответить · ⌘⇧Enter подробнее · ⌘⇧H показать/скрыть текст · ⌘⇧A Auto · ⌘⇧L язык речи
  (на Windows — Ctrl вместо ⌘).
- **Меню в трее** (значок в строке меню / в углу панели задач): начать/остановить встречу, вкл/выкл текста,
  положение, размер, ширина, прозрачность, автоскрытие, язык речи, язык ответа, движок.
- **Звук встречи без BlackHole**: на Mac — через ScreenCaptureKit (macOS 13+), на Windows — системный звук.
  Работает и с десктопными Zoom/Teams.

Скачать: страница `/download` на сайте (кнопка «Приложение» в шапке) — она сама предлагает версию под систему.
Установка: `MeetingCopilot-…-arm64.dmg` (Mac на M-чипе) / `…-x64.dmg` (Intel) / `MeetingCopilot-Setup-….exe`.
Сборки не подписаны: на Mac первый запуск — правый клик по приложению → «Открыть»; на Windows —
«Подробнее → Выполнить в любом случае». На Mac при первом старте разреши «Запись экрана и системного звука»
и микрофон (System Settings → Privacy & Security), затем перезапусти приложение.
При первом запуске вставь ссылку на копилот с токеном (её печатает `serve` или `deploy/push.sh`).

Собрать самому:
```bash
cd desktop && npm install --include=dev
npm start            # запустить из исходников
npm run dist:mac     # → desktop/dist/*.dmg
npm run dist:win     # → desktop/dist/*.exe и .zip
```

Если делишься **всем экраном**, собеседники увидят и текст поверх — делись окном/вкладкой со встречей.

## Язык

На стартовом экране, в шапке и в трее: **язык речи** (Авто — русский + английский и др. вперемешку, или
конкретный язык — точнее) и **язык ответа** (как в вопросе / всегда по-русски / always English).
Смена языка речи посреди встречи переподключает распознавание за ~1 с, транскрипт не теряется.

**Как распознавать точнее** (замер на речи через кодек Opus с шумом, Deepgram Nova-3, окт. 2026):
| Настройка | Ошибок в словах |
|---|---|
| Авто, без подсказок | ~31% |
| Авто + слова для распознавания | ~22% |
| Русский + слова для распознавания | ~19% |
- Встреча в основном на русском → выбери **Русский** (английские термины добавь в слова).
- **Слова для распознавания** (вкладка «Подготовка»): имена, названия, термины — Вардан, Greenplum, dm_visits, SLA.
  Ещё подсказки берутся из брифа, файлов к встрече и «Обо мне» (только аббревиатуры, названия, идентификаторы).
- Лимит: в режиме «Авто» — 10 слов (больше 10 английских подсказок заставляют Deepgram терять русскую речь —
  проверено), в одноязычном режиме — до 50. Обычные слова («Data», «Done») не добавляй: они мешают.
- Звук теперь сжимается до 16 кГц через фильтр нижних частот (раньше — усреднение, давало призвуки).

## Ответы — лента

Все ответы встречи остаются в панели: прокрути вверх, чтобы перечитать старые; новый ответ появляется внизу
крупно, старые — мельче. Если ты читаешь старый ответ, а Auto выдал новый — появится кнопка «Новый ответ ↓».
Перезагрузил страницу посреди звонка — транскрипт и все ответы вернутся, кнопка «Поделиться экраном и
продолжить» продолжит ту же встречу. Новая встреча начинается под разделителем, прошлые ответы остаются выше.

## Движки ответов

В шапке ответа — переключатель: **Быстро** (Haiku 5.5, ≈0.9 с) · **Умнее** (Sonnet 5.5) · **Глубоко** (Opus 5.5,
с размышлением) · **Максимум** (Fable 5.1). Выбранный движок отвечает по ⌥Space и в Auto.
**Подробнее** (⌥⇧Space) — тот же вопрос ещё раз движку «Максимум», с более развёрнутым ответом.
Модели и их параметры — `config.yaml → brain.engines`.

## Подготовка к встрече (вкладка «Подготовка» на сайте)

- **Обо мне** — постоянный текст (роль, опыт, проекты, цифры); подмешивается во все встречи.
- **К этой встрече** — с кем созвон, повестка, цель; действует только для текущей встречи.
- **Слова для распознавания** — см. раздел «Язык».
- **Файлы, папки и чаты** — перетащи файлы, **целые папки** или zip (в т.ч. zip с папками и zip в zip):
  выгрузки чатов (Telegram HTML/JSON, claude.ai, ChatGPT), PDF, Word, Excel, PowerPoint, SQL и код, CSV, JSON,
  Jupyter, MD, TXT, RTF. Путь сохраняется («Проект/договоры/2025/договор.pdf») — по нему тоже ищется, а Claude
  видит карту загруженных материалов. Фото, видео, `.git`, `node_modules` и пустые файлы пропускаются.
  Выбери: «Только к этой встрече» (живёт до конца встречи) или «Сохранить в мою базу» (постоянно).
Всё хранится под твоим пользователем в `data/private/owner/` и другим не видно.
Zip чата можно бросить и прямо на стартовом экране, до начала звонка — он подключится к этой встрече.

**Большие файлы.** До 150 МБ за раз (zip с выгрузкой Telegram, PDF на сотни страниц, архив claude.ai).
Ничего не обрезается: чат на 300 тыс. сообщений индексируется целиком (~5–8 с), фото/видео/голосовые внутри
zip пропускаются. Если файл больше — выгрузи чат без медиа или по отдельным чатам/периодам.
Загружай **до звонка**: тогда (1) поиск уже готов к первому вопросу и (2) названия и аббревиатуры из файлов
(SLA, Greenplum, dm_visits…) передаются распознаванию речи — оно перестаёт путать «SLA» со «слова».

**Как копилот ищет по файлам.** На каждый вопрос находит до 3 мест, где слова вопроса стоят в одном
сообщении/предложении (русские словоформы и частые рабочие термины RU↔EN сопоставляются: «deadline» найдёт
«дедлайн», «visits» — «dm_visits»), и отдаёт Claude эти места с соседними сообщениями и датой.
Если ничего не нашлось — быстрая модель подбирает синонимы («приступить к работе» → «выйти на работу») и ищет
ещё раз (+~1 с). При противоречиях Claude опирается на более свежее сообщение; команды внутри файлов не выполняет.

## Мои чаты (личная база, только для тебя)

Ответы могут опираться на твои прошлые переписки. База лежит локально в `data/private/owner/` и
подключается только к сессиям владельца — у других пользователей её нет.

```bash
# claude.ai: Settings → Privacy → Export data → придёт письмо со ссылкой на .zip
uv run python -m copilot import-chats ~/Downloads/<выгрузка-claude>.zip
# Telegram Desktop: Settings → Advanced → Export Telegram data → формат JSON
uv run python -m copilot import-chats ~/Downloads/Telegram\ Desktop/ChatExport_*/result.json
# также: выгрузка ChatGPT (conversations.json), любые .md/.txt, целые папки
uv run python -m copilot search-chats "витрина визитов"     # проверить, что находится
```

На сайте появится тумблер **«Мои чаты · N»**; под ответом видно, из каких чатов взят контекст.
